# 미용실 예약 (웹앱)

아이폰·안드로이드 모두에서 인터넷 주소로 여는 미용실 예약 관리 앱입니다. 로그인이 없고, 고객 정보는 각 휴대폰 안에만 저장됩니다.

- 고객 이름, 전화번호, 첫 예약날짜, 주기(주 단위), 예약 시간, 메모
- 방문 완료를 누르면 다음 예약일을 주기만큼 뒤로 자동 계산
- 예약 1주일 전·당일 알림 대상이 메인 화면에 모여 보이고, **문자 보내기**를 누르면 내용이 채워진 문자앱이 열림
- 휴대폰 캘린더 알림 등록(.ics), 백업 파일 저장·불러오기
- 홈 화면에 추가하면 앱처럼 열리고, 인터넷이 잠깐 끊겨도 열림

## 파일
- `index.html`: 앱 전체 (화면, 저장, 문자)
- `sw.js`: 오프라인용 서비스 워커. 앱을 고치면 `VERSION`을 올려야 휴대폰에 새 버전이 퍼짐
- `manifest.webmanifest`, `icons/`: 홈 화면 아이콘
- `gowun-batang-bold.woff2`: 고운바탕 글꼴 (SIL Open Font License), 한글 2,350자 서브셋
